# DIMEN

The objective is to solve puzzles using a dimensional camera, capable of transforming the environment from 3D to 2D, allowing the player to overcome obstacles that are impossible in 3D. The player also interacts with various elements in the environment, such as movable cubes, keys, and platforms.

## Prerequisites
- .NET 8.0.X installed  
  https://dotnet.microsoft.com/en-us/download/dotnet/8.0  
- Install the **.NET Runtime** for your operating system

## Launch
1. Clone the project
2. Navigate to:
   `..\DIMEN\DIMEN\bin\Debug\net8.0`
3. Run `DIMEN.exe`

Enjoy the game!
